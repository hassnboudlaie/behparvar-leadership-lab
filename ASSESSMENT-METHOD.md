# Behparvar attention triangle — educational prototype, version 2

This original workshop activity describes situational first priorities. It is not a validated psychometric test, personality diagnosis, performance ranking, or the two-dimensional Blake–Mouton Leadership Grid. The company's public production/distribution context informs the fictional cases; none claims to describe an actual company incident. Quality, safety and authority requirements remain fixed constraints.

## One case, one choice

Eight short cases each offer three professionally plausible first actions under a time constraint. Each action emphasizes one of task, people or context. No all-inclusive ideal action is supplied. Response positions rotate across dimensions. Participants select one action per case, may change it or navigate freely, and see a provisional point after their first choice. The final interpretation requires all eight choices.

Each selected first priority contributes exactly one categorical count to its emphasized dimension, with no artificial baseline allocated to the other dimensions. This replaces version 1's two ranked actions and positive-floor weights, which compressed results toward the center. A zero contribution describes the focus of that selected action, not an absence of concern or competence. Consistently selecting one dimension can now reach its vertex; genuinely varied selections can still produce a central result. We do not stretch scores or force a distribution of participants across profiles.

For counts S=(T,P,C), shares are S/sum(S). Integer percentages use largest-remainder rounding and sum to 100. Point coordinates use unrounded shares and the barycentric weighted average of vertices task=(210,60), people=(375,295), context=(45,295). Grid lines mark 20%, 40%, 60%, 80%. No participant point appears before a valid choice. Only one live triangle is rendered, on the assessment page; the optional model reference does not repeat the personal plot.

## Seven descriptive summaries

Sort dimension counts descending. If first minus second is at least 2, use the leading dimension's summary. Otherwise, if second minus third is at least 2, use the two leading dimensions' summary. All other complete results use the varied-priority summary. These are transparent editorial rules for short educational feedback, not statistically derived cutoffs or normative classifications.

Reachable fixtures: (8,0,0)=T, (0,8,0)=P, (0,0,8)=C, (4,4,0)=TP, (4,0,4)=TC, (0,4,4)=PC, (3,3,2)=M. The last profile makes no claim of superior balance. A relative composition cannot measure absolute capability or demonstrate that all dimensions were considered within each decision.

After completion, participants open “مشاهده تحلیل من” on the same page. Four short sections provide meaning anchored to their chosen cases, a possible strength/blind spot, relevant learning, and one suggested workplace experiment before the next session. The suggestion links to a separate private practice page. Optional methodology and case navigation remain collapsed initially.

## Storage and privacy

Responses, interpretation visibility and notes use the existing browser-local workshop state with `triangle.version=2`. No answer or result is submitted to a teacher or scoring service. Shared-browser users can see locally retained data. Version 1 responses are retained under `trianglePrevious` but are never reinterpreted under changed questions/scoring; the new exercise starts empty. Other module answers and notes are preserved. A scoped assessment reset clears both triangle versions while preserving other work. The separate explicit full-course reset clears all workshop state. Blocked storage still allows the exercise to function for the current visit and displays a persistence warning.

## Course layout and checks

Module one has a three-step, 25-minute core: assessment (8), a single group case (12), and three-question takeaway (5). The detailed model, office case and handout are optional linked resources. Redundant case quizzes and a second reflection quiz have been removed; old saved answers are preserved. The case uses three disclosures for task, people and context, supporting discussion rather than another score. The post-class practice form is shared with the workshop closing and retains situation/timing, behavior and later evidence. The short handout contains three linked practical tools; printing expands and then restores them. A separate 120-minute facilitator guide links to all eight modules.
