# Behparvar Leadership PWA

Independent mobile-first app: https://hassnboudlaie.github.io/behparvar-leadership-lab/app/

Source of truth: ../index.html (all real learning materials, cases, assessments, role-plays). 6 sessions x 7 sections. Audience paths: managers / supervisors. App uses a same-origin iframe to reuse original lessons, avoiding content duplication. Existing training website remains unchanged.

Official company brand mark is read from the source site's own embedded PNG image. App shell initially uses the identical original company logo URL. Photographs from existing official company asset folder.

Leadership Passport: device-only last visited section, manual completion markers and bookmarks. No automatic quiz results or teacher analytics, no user accounts, and no central storage.

GitHub Pages is public even when this app's link is shared internally; do not put confidential company or staff data in this repository. The shell can cache offline, but training content requires a connection. For a private deployment add access controls separately.
